# Quiz Game (Python)

## Description

This is a simple command-line quiz game built using Python. The program asks the user a series of questions and checks whether the answers are correct.

## Features

* Multiple questions
* User input for answers
* Score calculation
* Simple command-line interface

## Purpose

This project was created to practice basic Python concepts such as:

* Input and Output
* If-else statements
* Variables
* Basic program logic
